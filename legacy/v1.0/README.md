# HITL-IoT v1.0 — superseded, kept for provenance only

> **Do not use these files for new experiments or comparisons.** Use [`data/v1.1/`](../../data/v1.1/).

This folder preserves the original v1.0 release (tag [`v1.0.0`](../../../../releases/tag/v1.0.0), 9 December 2025) so that earlier work can be traced. It was superseded by v1.1 for two documented reasons (see [`data/v1.1/CHANGELOG_v1.1.md`](../../data/v1.1/CHANGELOG_v1.1.md)):

1. **Label shortcuts.** Several v1.0 fields separated benign and attack flows by construction (for example, a constant destination MAC address for attacks and all attacks using TCP). Models trained on v1.0 can reach near-perfect scores without learning attack behaviour; the v1.0 baseline numbers are therefore not comparable with v1.1.
2. **Provenance wording.** The file `data/HITL-IoT_human_annotations.csv` and the v1.0 documentation describe "human", "expert", "intermediate" and "novice" annotations. **These records were generated by simulation, not collected from people.** The file name is kept unchanged only so that its published SHA-256 digest still verifies.

| Path | v1.0 content |
|---|---|
| `data/` | v1.0 dataset, simulated oversight records and checksums |
| `notebooks/` | v1.0 exploratory analysis and baseline notebooks |
| `benchmark_results/` | v1.0 figures, tables and trained models |
