A benchmark for decisions beyond detection

HITL-IoT v1.1 is a deterministically generated, controlled smart-home IoT network-flow benchmark. It supports research on intrusion detection, calibrated confidence, uncertainty-aware review, selective prediction and learning to defer.

Data provenance: The network traffic is generated, not captured from an operational network. The 10,227-record oversight subset contains simulated profile decisions, confidence, latency and generated rationales, not judgments from recruited cybersecurity professionals. Profile labels must not be interpreted as measured analyst expertise.

Benchmark essentials

  • 127,845 flows: 108,668 benign and 19,177 attack
  • 60 dataset columns, with 39 permitted primary IDS features
  • 5 IoT device types and 12 device instances
  • 12 attack families across four threat groups
  • Frozen chronological train/validation/test splits and reproducibility checks
  • Nine-model baseline and oversight evaluation protocols

Research applications

Intrusion detection

Evaluate benign/attack classification with the same frozen benchmark split.

Probability calibration

Study whether IDS confidence reflects observed prediction reliability.

Selective prediction

Evaluate risk–coverage trade-offs when uncertain predictions are deferred.

Review allocation

Measure which errors are reached under a fixed simulated-review budget.

Learning to defer

Compare model-only and simulated reviewer-assisted decision policies.

External validation

Study domain shift using independently collected CICIoT2023 and ToN-IoT data.

Data and reproducibility

Source code, notebooks, schemas and feature policy are available in the v1.1 preparation branch. The full frozen v1.1 dataset and experimental ZIP files are planned as separately downloadable GitHub Release assets. Until those assets appear, do not assume they are available from the source tree.

Official repository and release files

Download individual dataset and results assets after the v1.1 release is published. The v1.0 archive remains available for historical reproducibility.

Reference results — chronological test split

The accepted manuscript reports a nine-model evaluation using 70/15/15 chronological training, validation and test partitions. These are manuscript-reported outcomes, not independent retraining of the downloadable archives.

How to cite HITL-IoT

Associated article — accepted for publication, in copyediting:

Wakili, A., Idris, M., and Bakkali, S. HITL-IoT: A Reproducible Dataset and Benchmark for Studying Trustworthy Human–AI Collaboration, Oversight Mechanisms, and Selective Deferral in IoT Cybersecurity. BenchCouncil Transactions on Benchmarks, Standards and Evaluations (TBench). Accepted; publication DOI and bibliographic details pending.

Dataset citation

For reproducibility, cite both the article and the exact dataset version when the corresponding identifiers are published. The machine-readable CITATION.cff includes the accepted paper. The verified Zenodo DOI for dataset v1.1 will be added after its public deposit.
