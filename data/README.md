# Dataset files

[`v1.1/`](v1.1/) is the frozen HITL-IoT research dataset. It is kept separate from the historical `data/Dataset/` path found in the older GitHub repository.

The original dataset filenames and source SHA-256 hashes are unchanged. For integrity checks use `python scripts/validate_original_release.py`. See [`v1.1/README.md`](v1.1/README.md) for file descriptions.
